# PhisherSim

PhisherSim is a simulation tool designed to help users understand and recognize phishing attempts in a controlled environment. This project provides educational resources and interactive scenarios to improve cybersecurity awareness.

## Features

- Simulated phishing scenarios
- User training modules
- Reporting and analytics
- Customizable templates

## Installation

1. Clone the repository:
    ```
    git clone https://github.com/yourusername/phishersim.git
    ```
2. Place the files in your web server directory (e.g., `htdocs` for XAMPP).
3. Start your web server (Apache, XAMPP, etc.).

## Usage

- Access the application via your browser at `http://localhost/phishersim/`.
- Follow the on-screen instructions to begin a simulation or training module.
